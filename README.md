# ICU Capacity Dashboard

A synthetic-data pipeline and Streamlit dashboard for monitoring intensive-care
capacity. It ingests 90 days of occupancy records for 15 fictional hospitals in
NRW and Saxony, validates and cleans them, pseudonymizes facility identities, and
shows which hospitals run above a chosen occupancy threshold, and when.

## What it demonstrates

- **Data quality handling:** duplicates, missing values and impossible values are
  detected, corrected and flagged, never silently overwritten.
- **Privacy-aware processing:** facility identifiers are hashed (SHA-256) and the
  original identifying column is dropped.
- **Decision-ready analytics:** filter by region and date range, see which
  facilities exceed a capacity threshold, and follow each facility's occupancy trend.

## How it works

|
| 1. Generate | `generate_synthetic_data.py` | Creates the raw dataset (15 fictional hospitals, 90 days) with data-quality problems injected on purpose. The assumptions are documented in the docstring. |
| 2. Ingest | `ingest_data.py` | Checks for duplicates, missing and impossible values, then cleans them. Missing occupancy is imputed from each hospital's own median, and every correction is flagged in a boolean column. |
| 3. Pseudonymize | `anonymize.py` | Hashes the hospital ID with SHA-256, drops the original ID column, runs a lightweight k-anonymity check on the remaining quasi-identifiers, and computes the occupancy metrics. |
| 4. Visualize | `app.py` | Streamlit dashboard with region and date filters, threshold highlighting and per-facility trends. |

## Run it

```bash
pip install -r requirements.txt
python generate_synthetic_data.py
python ingest_data.py
python anonymize.py
streamlit run app.py
```

## Tech stack

Python, pandas, Streamlit

## Data note and limitations

All hospital names and figures are synthetic and generated by
`generate_synthetic_data.py`. No real patient or hospital data is used.
SHA-256 hashing is pseudonymization, not full anonymization, and this project
is a technical demonstration, not a certified compliance solution.
